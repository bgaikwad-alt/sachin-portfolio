Finance · Legacy modernisation

Mortgage Loan Reporting Utility

Designed and digitally transform legacy app systems for major finance and asset management giant in the US.

ClientAEGON Asset Management
RoleVisual Design, UI Designer, Responsive HTML Designer
Duration7 weeks
TeamBusiness Stakeholders, Marketing, Client, PM, Technical Architects, Sr. Jr. Dev, and Testing Teams
ToolsDraw iO, Responsive Bootstrap 5.3.0 Framework, VS Code (Visual Studio Code)

Challenge & Scope

The legacy application, which was 20 years overdue for an update, necessitated the use of multiple applications to access customer reports. This reliance on manual intervention processes increased the risk of human error and data discrepancies, making the task cumbersome and time-consuming for account managers. The primary challenge involved designing and developing five applications within a six-month timeframe, all while adhering to stringent data security and access restrictions. For security reasons, the client insisted on using only default Bootstrap classes, avoiding any third-party plugins or code.

The Solution

Re-designed the application flow by eliminating redundant info, unwanted data and unnecessary process workflows, based on high-level discussions and client interactions. Created dashboard UIs tailored for super admin, admin, and account manager roles, and developed responsive HTML designs with default bootstrap classes. Simplified complex forms into intuitive designs and crafted responsive tables. Established a reusable template for consistent UI across five applications, enhancing brand cohesion. Final design assets were handed over to development teams for implementation.

Achievement

After multiple feedback sessions and iterations, the client adopted my HTML designs as their standard brand guidelines for all internal applications. Our team secured two additional application revamps after delivering designs for five applications.
